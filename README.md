# 台灣數位韌性守護網

<h2 align="center">台灣數位韌性守護網</h2>

<p align="center">Defending Democracy Online: A Digital Resilience Toolkit<br>網軍防禦/數位韌性科技工具箱<br><br>以開源精神與公民參與為核心，蒐集整合數位韌性工具、研究資源與實踐方法，聚焦於數位韌性、社群安全與認知戰防禦能力的培育。協助使用者在日常網路使用中建立清晰的判斷能力，並在風險情境下維持資訊流通與社群信任。</p>
